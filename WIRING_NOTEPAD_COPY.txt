IMPORTANT POWER RULES
---------------------

1. Do NOT power DC motors from Raspberry Pi 5V.
2. Use a separate motor battery for the L911S motor driver.
3. Raspberry Pi GND, L911S GND, sensor GND, servo GND, and motor battery negative must share common ground.
4. Raspberry Pi GPIO pins are 3.3V logic.
5. HC-SR04 Echo is 5V. Use a voltage divider or level shifter before connecting Echo to Raspberry Pi GPIO.


RASPBERRY PI 2B PIN MAP
-----------------------

Use BCM GPIO numbers in code.

----------------------------------------------------------

Left motor reverse               GPIO6        Pin 31
Right motor forward              GPIO13       Pin 33

MINIMAL DEMO WIRING
-------------------

Use this if you want the simplest working rover.

Raspberry Pi USB port -> USB webcam

Raspberry Pi GPIO5  -> L911S A-IA
Raspberry Pi GPIO6  -> L911S A-IB
Raspberry Pi GPIO13 -> L911S B-IA
Raspberry Pi GPIO19 -> L911S B-IB

Raspberry Pi GND -> L911S GND
Motor battery positive -> L911S VCC / VM
Motor battery negative -> L911S GND
L911S Motor A output -> Left DC motor
L911S Motor B output -> Right DC motor

Do not connect ESP32-S3 motor pins in this mode.


L911S DIRECT RASPBERRY PI MOTOR WIRING
--------------------------------------

L911S Pin        Connect To
---------------------------
A-IA             Raspberry Pi GPIO5, physical pin 29
A-IB             Raspberry Pi GPIO6, physical pin 31
B-IA             Raspberry Pi GPIO13, physical pin 33
B-IB             Raspberry Pi GPIO19, physical pin 35
VCC / VM         Motor battery positive
GND              Motor battery negative and Raspberry Pi GND
Motor A output   Left DC motor
Motor B output   Right DC motor

Config:

"direct_motor_control": true
"esp32_serial_control": false


ESP32-S3 OPTIONAL MOTOR BRIDGE
------------------------------

Use ESP32-S3 only if you want this:

Raspberry Pi -> USB serial -> ESP32-S3 -> L911S -> motors

Do NOT connect Raspberry Pi motor GPIO pins and ESP32-S3 motor GPIO pins to the L911S at the same time.

Raspberry Pi To ESP32-S3:

Raspberry Pi USB port -> ESP32-S3 USB / UART port

ESP32-S3 To L911S:

ESP32-S3 GPIO4 -> L911S A-IA
ESP32-S3 GPIO5 -> L911S A-IB
ESP32-S3 GPIO6 -> L911S B-IA
ESP32-S3 GPIO7 -> L911S B-IB
ESP32-S3 GND   -> L911S GND

L911S power:

Motor battery positive -> L911S VCC / VM
Motor battery negative -> L911S GND
L911S Motor A output -> Left DC motor
L911S Motor B output -> Right DC motor

ESP32-S3 firmware:

rover/esp32_s3/stasis_motor_controller.ino

Serial:

Baud rate: 115200
Command format: M:left_speed,right_speed
Stop command: M:0,0

Config for ESP32-S3 motor mode:

"direct_motor_control": false
"esp32_serial_control": true
"esp32_serial_port": "/dev/ttyUSB0"
"esp32_baudrate": 115200

If Pi shows /dev/ttyACM0, use:

"esp32_serial_port": "/dev/ttyACM0"

FAULT-TOLERANT BEHAVIOR
-----------------------

If ultrasonic is missing -> ultrasonic disabled, rest keeps working.
If servo is missing -> servo disabled, rest keeps working.
If MPU6050 is missing -> IMU disabled, rest keeps working.
If compass is missing -> compass disabled, rest keeps working.
If motor driver is missing -> motor output disabled, sensors/camera/object detection keep working.
If ESP32-S3 is missing but direct Pi motors are enabled -> ESP32-S3 is not needed.
If ESP32-S3 mode is enabled but ESP32-S3 is missing -> motor output disabled, camera/object detection keep working.
