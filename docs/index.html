Pi Camera Stream

The USB webcam stays on the rover so the dashboard sees the scene from the Raspberry Pi.

Detection Alerts

Dataset Studio

A webcam tool helps collect training photos for custom alpha tester objects.

Custom Object Detection

STASIS is being prepared for a specific trained object detection model instead of relying only on generic classes.

Training Plan

Collect real demo photos from webcam and phone, label alpha tester objects, red strips, and empty backgrounds, then train a small detector for the exact demo environment.

Rover To Laptop To Dashboard

The Raspberry Pi captures frames and controls the rover. The Windows laptop handles the web dashboard and heavier vision work.

1

2

3

4
Results return to the Pi.
5
Dashboard tracks and controls.

Start It

Run the Windows server first, then point the Raspberry Pi rover client to the server IP.

cd server
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements-api.txt
copy vision_config.example.json vision_config.json
python security_rover_server_windows.py
cd ~/Documents/Stasis/rover/rpi2b
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp config.example.json config.json
nano config.json
python rover_client.py --config config.json
