No GPS theater, no fake field infrastructure. STASIS is tuned for an indoor forest-like arena where the rover can see, report, stop, scan, and respond.

Start the demo.

Run the Windows server first, then point the Raspberry Pi rover client at the laptop IP.

cd server
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements-api.txt
python security_rover_server_windows.py

cd ~/Documents/Stasis/rover/rpi2b
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python rover_client.py --config config.json
