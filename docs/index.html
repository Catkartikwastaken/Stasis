STASIS

A compact rover system for indoor forest-style monitoring, Raspberry Pi camera streaming, object detection, and browser-based control.

What It Does

STASIS keeps the hardware small and shifts heavier processing to the laptop or configured AI provider.

Rover Camera

The USB webcam stays on the Raspberry Pi so the dashboard sees the rover's point of view.

Human And Object Alerts

Detections become dashboard alerts with confidence, category, and target location for tracking.

Dataset Studio

A simple webcam app helps collect alpha tester object, red strip, and empty background images.

Architecture

The Raspberry Pi captures frames and controls the rover. The Windows server handles the dashboard and heavier vision work.

1
Pi webcam captures the scene.
2
Frames stream to Windows.
3
Vision provider detects targets.
4
Results return to the Pi.
5
Dashboard shows alerts and controls.

Quick Setup

Start the Windows server first, then connect the Raspberry Pi rover client to the server IP.

cd server
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements-api.txt
copy vision_config.example.json vision_config.json
python security_rover_server_windows.py
cd ~/Documents/Stasis/rover/rpi2b
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp config.example.json config.json
nano config.json
python rover_client.py --config config.json
