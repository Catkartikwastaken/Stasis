Field operation

Rover vision for real terrain

The rover side captures camera frames and status data, then sends them to the Windows server for display, detection, and alert routing.

Local decision loop

Detection, context, response

STASIS can combine object detection with a local model through Ollama or LM Studio so the system can summarize what it sees and decide what deserves attention.

detect

Run camera frames through local YOLO or ONNX providers.

alert

Raise events for people, animals, signs of fire, tracks, and markers.

reason

Send selected observations to Qwen or another local model for plain-language output.

How the pipeline moves.

A simple split: the Pi handles capture and rover-side telemetry; the laptop handles heavier inference, the dashboard, and local model workflows.

01

Capture

Pi camera frames and rover state are collected close to the sensor.

02

Transmit

WebSocket channels carry frames, status, and detection payloads.

03

Infer

Windows-side providers run object detection and prepare alert context.

04

Act

The dashboard surfaces events and can hand observations to a local LLM.
