Built For A Small Rover Demo

The project keeps the hardware compact while still covering live video, AI detection, command control, tracking, and custom dataset collection.

Pi Camera Stream

The USB webcam stays on the rover so the dashboard sees the scene from the Raspberry Pi.

Detection Alerts

Humans, demo objects, and red strips become dashboard events with confidence and location.

Dataset Studio

A polished webcam tool helps collect training photos for the custom alpha tester objects.

Rover To Laptop To Dashboard

The Raspberry Pi captures frames and controls the rover. The Windows laptop handles the web dashboard and heavier vision work.

Start It

Run the Windows server first, then point the Raspberry Pi rover client to the server IP.

cd server
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements-api.txt
copy vision_config.example.json vision_config.json
python security_rover_server_windows.py
cd ~/Documents/Stasis/rover/rpi2b
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp config.example.json config.json
nano config.json
python rover_client.py --config config.json
