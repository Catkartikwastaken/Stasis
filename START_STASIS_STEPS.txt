STASIS START AGAIN STEPS
========================

Use this when you want to start fresh and make rover work again.


PART 1 - UPDATE CODE ON RASPBERRY PI
------------------------------------

1. Open terminal on Raspberry Pi.

2. Go to project folder:

cd ~/Documents/Stasis

3. Pull latest GitHub code:

git pull origin main

4. Go to Pi rover folder:

cd ~/Documents/Stasis/rover/rpi2b

5. Activate Python environment:

source .venv/bin/activate


PART 2 - CHECK MODEL FILES
--------------------------

1. Check models folder:

ls -la models

2. For Pi-only fallback, you can keep this custom NCNN model folder:

models/best_ncnn_model

3. For the fast Windows laptop detector, the Windows server should have:

server/models/yolo11n.onnx
server/models/stasis_custom.onnx
server/models/stasis_custom.labels.txt

4. You should also have these Pi-only fallback common detector files:

models/coco.names
models/ssd_mobilenet_v3_large_coco_2020_01_14.pbtxt
models/frozen_inference_graph.pb

5. If best_ncnn_model is missing, copy it to:

~/Documents/Stasis/rover/rpi2b/models/best_ncnn_model


PART 3 - MAKE NEW CONFIG
------------------------

1. Backup old config:

cp config.json config.old.json

2. Copy latest object detection config:

cp object_detection_config.example.json config.json

3. Edit config:

nano config.json

4. Set server_host to your Windows laptop IP.

Example:

"server_host": "192.168.29.69",

5. Inside object_detection, make sure these lines exist:

"backend": "combined",
"yolo_model_path": "models/best_ncnn_model",
"target_classes": [],
"common_detection_enabled": true,
"common_target_classes": ["person", "cell phone"],
"confidence_threshold": 45,
"max_box_area_percent": 80.0,
"green_strip_enabled": false,
"overlay_enabled": true

6. Save nano:

CTRL + O
Enter
CTRL + X


PART 4 - INSTALL PI PACKAGES
----------------------------

Run these on Raspberry Pi:

pip install -r requirements.txt
pip install -r requirements-object-detection.txt

For NCNN model folders, do not install ultralytics on the Pi.

Only if you are trying to run a .pt model directly, run:

pip install ultralytics

If ultralytics fails because of torch, tell Codex exact error.


PART 5 - START WINDOWS SERVER WITH LAPTOP DETECTION
---------------------------------------------------

1. Open PowerShell on Windows laptop.

2. Go to server folder:

cd C:\Users\haris\Downloads\Stasis-main\Stasis\server

3. Activate environment:

.\.venv\Scripts\activate

4. Start the faster laptop-side YOLO server:

set STASIS_OBJECT_ANALYSIS_INTERVAL_SECONDS=0.25
set STASIS_YOLO_INPUT_SIZE=640
set STASIS_CUSTOM_YOLO_INPUT_SIZE=416
python security_rover_server_object_detection.py

5. Keep this PowerShell window open.

6. Open dashboard in browser:

http://127.0.0.1:5000

Or from phone/Pi network:

http://YOUR_WINDOWS_LAPTOP_IP:5000


PART 6 - START PI ROVER STREAMING ONLY
--------------------------------------

On Raspberry Pi terminal:

cd ~/Documents/Stasis/rover/rpi2b
source .venv/bin/activate
python rover_client.py --config config.json


PART 7 - GOOD OUTPUT SHOULD SHOW
--------------------------------

Look for these lines:

Configuration successfully loaded
WebSocket handshake successful
Streaming Raspberry Pi webcam


PART 8 - TEST OBJECTS
---------------------

Show these to camera:

1. Your trained demo object
2. Green strip
3. Human face/body
4. Mobile phone

Expected:

Windows laptop detects human, cell phone, animals, your trained demo objects, and green strip.
common COCO model detects person and cell phone
dashboard shows boxes on livestream
dashboard green strip buttons send green_strip marker commands


PART 9 - IF IT DOES NOT WORK
----------------------------

If GitHub code did not update, run:

cd ~/Documents/Stasis
git pull origin main

Then check:

grep -n "common_detection_enabled\|common_target_classes\|green_strip" rover/rpi2b/object_detection_config.example.json

If model missing:

ls -la ~/Documents/Stasis/rover/rpi2b/models

If server connection fails:

Check Windows laptop IP.
Make sure Windows server is still running.
Make sure Pi config server_host matches Windows IP.

If detection does not start:

Send Codex the Pi terminal output after running:

python rover_client_object_detection.py --config config.json
